# Безкоштовна публікація

Перевірено 2026-09-21. Варіант для невеликої гри з друзями: **Render Free Web Service**.

Один Node.js-процес обслуговує зібраний клієнт із dist та WebSocket на /socket. Гра, VR і онлайн мають одну HTTPS-адресу. Окремий статичний хостинг, база даних або платний домен для цього варіанта не потрібні.

## Підготовлено у репозиторії

- render.yaml — безкоштовний план, команди збірки/запуску, health check.
- npm run build — TypeScript-перевірка, production-клієнт та production-сервер.
- npm start — звичайний Node.js виконує dist-server/index.mjs; Vite/tsx на runtime не використовуються.
- У production сервер перевіряє наявність dist/index.html і дозволений Origin.
- На Render власний публічний Origin береться з RENDER_EXTERNAL_URL; для власного домену потрібно явно задати ALLOWED_ORIGINS.
- MAX_ROOMS=2 у безкоштовному профілі — обережний початковий ліміт, а не підтверджена місткість безкоштовного CPU.

## Кроки

1. Використати підготовлений репозиторій [Erchard/V3DarioVR](https://github.com/Erchard/V3DarioVR).
2. Зареєструватися на Render та підключити GitHub.
3. Вибрати New → Blueprint, указати репозиторій і використати render.yaml.
4. Перевірити, що план саме Free. Запустити розгортання.
5. Дочекатися успішного deploy. Render надасть адресу https://назва.onrender.com.
6. Відкрити її на ноутбуці, зіграти локальний матч, потім створити онлайн-кімнату та приєднатися з іншого браузера.
7. Відкрити ту саму HTTPS-адресу у Quest Browser і перевірити VR на фізичному шоломі.

Альтернатива через форму New → Web Service:
- Runtime: Node.
- Plan: Free.
- Build Command: npm ci --include=dev && npm run build.
- Start Command: npm start.
- Health Check: /readyz.
- NODE_ENV=production; MAX_ROOMS=2.

Не задавати PORT вручну: сервер читає порт, виданий платформою, і слухає 0.0.0.0.
Не заповнювати VITE_SERVER_URL для стандартного розгортання — клієнт автоматично використовує WSS /socket на власному origin.

## Реальні обмеження безкоштовного плану

Сервіс засинає після 15 хвилин без HTTP/WebSocket активності. Наступний вхід запускає його знову, що може тривати близько хвилини. Активні WebSocket-повідомлення враховуються як активність.
На workspace виділено 750 годин роботи безкоштовних інстансів на календарний місяць. Є окремі ліміти вихідного трафіку та build minutes; перевіряти їх у Dashboard. За відсутності платіжного методу перевищення відповідних лімітів призводить до призупинення сервісу/збірок, а не безмежної безкоштовної роботи.
Render може перезапускати free-сервіс; активні матчі з оперативної пам'яті при цьому втрачаються. Постійний рейтинг/акаунти у цій версії не передбачені.

Цей варіант підходить для демонстрації й гри з друзями. Безперервний публічний сервіс з гарантованою продуктивністю потребуватиме іншого бюджету та приймальних вимірів.
Опубліковано: [v3dario.onrender.com](https://v3dario.onrender.com). HTTPS, readiness, WSS і старт спільної кімнати перевірені. Наступні зміни потрібно перевіряти після розгортання; успішний Git push сам по собі не підтверджує deploy.
