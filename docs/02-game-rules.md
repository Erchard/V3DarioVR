# Правила та баланс, rulesVersion = 1

Усі координати — ігрові одиниці, час — секунди, маса — умовні одиниці. Формули — проєктні правила, а не фізична модель.

## Єдиний початковий профіль arena3d

| Параметр | Значення |
| --- | --- |
| Вимірність | 3; координати x,y,z |
| Арена | куб 80 × 80 × 80, центр (0,0,0) |
| Боти в одиночному режимі | 8 |
| Початкова кількість їжі / ціль | 800 |
| Маса їжі | 1 |
| Стартова / максимальна маса клітини | 20 / 2000 |
| Базовий радіус r0 при масі 20 | 1 |
| Базова / мінімальна швидкість | 5 / 1.5 |
| Тривалість матчу | 300 секунд |
| Крок симуляції | 1/60 секунди |
| Поріг переваги маси | 1.15 |
| Захист після спавну | 3 секунди |
| Респавн бота | через 3 секунди |

Один профіль для Chrome і VR; графічна якість не змінює правила.
Конфігурація незмінна протягом матчу. Відхилити запуск, якщо значення не скінченні, маса/розмір/крок непозитивні, minSpeed > v0, захист < 0 або максимальний радіус не вміщується в арену.

## Розмір і рух

Для маси m: r = r0 × (m / 20)^(1/3).
Швидкість v = clamp(v0 × (20/m)^0.15, minSpeed, v0).
Вектор команди u має довжину від 0 до 1; якщо довший — нормалізується. Переміщення за крок: position += u × v × dt.
Використовується вся довжина 3D-вектора, щоб діагональ і рух вгору не давали переваги.

Координата центра по кожній активній осі обмежена [-halfSize+r, halfSize-r]. Після росту повторно застосувати межі. Немає відбиття, інерційного ковзання чи проходу через край. Непоглинальні клітини можуть перекриватися; фізичного відштовхування немає.

## Поглинання

Їжа поглинається, коли відстань між її центром та центром клітини <= r клітини. Візуальний радіус їжі не бере участі в розрахунку.
Клітина A поглинає B, якщо одночасно:
- mA >= 1.15 × mB;
- distance(A,B) + 0.5 × rB <= rA;
- обидві живі та в обох закінчився захист.

Нова маса A = min(2000, mA+mB). Їжа додає 1 з тим самим обмеженням. Надлишок на межі 2000 зникає; це явний виняток зі збереження маси.
Під час захисту можна рухатись і збирати їжу, але не поглинати інших і не бути поглинутим.

## Порядок одного tick

1. Застосувати валідні команди й заплановані спавни; час обчислюється з номера tick.
2. На tick, кратному 6, оновити наміри ботів; перемістити живі клітини та застосувати межі.
3. Зафіксувати копію позицій, мас і радіусів для розв'язання зіткнень.
4. Знайти допустимі пари клітин. Сортувати хижаків за масою спадно, потім за ID лексикографічно; їхні жертви — за ID. Якщо учасник уже поглинутий цього tick, пропустити пару.
5. Для кожної їжі за ID вибрати серед живих після кроку 4 клітин, що накривали її у копії кроку 3: найбільша маса, потім найменший ID. Видалити їжу один раз.
6. Застосувати накопичену масу, оновити радіуси та межі. Ріст не дає нового ланцюга поглинань до наступного tick.
7. Виконати поповнення їжі за розкладом, оновити таблицю, перевірити смерть/кінець матчу.

Усі перевірки маси/геометрії у кроках 4–5 використовують копію кроку 3. ID унікальні в матчі та ніколи не перевикористовуються. Швидкості й крок підібрані для поточних розмірів; при додаванні ривків/поділу потрібна swept collision перевірка.

## Спавн та їжа

Стартова їжа рівномірно розміщується seeded PRNG усередині арени з відступом 0.2 від меж; їжа не перекриває початкові клітини. Для кожної спроби позиції максимум 32 вибірки; якщо розміщення неможливе, кількість тимчасово нижча за ціль.
Кожні 60 tick додати до 20 одиниць їжі, не перевищуючи ціль. Не розміщувати нову їжу всередині живої клітини.

Для клітини обрати до 32 позицій з відступом її радіуса. Безпечна позиція: відстань до кожної іншої клітини >= сума радіусів + 4. Якщо немає — вибрати кандидата з найбільшою мінімальною відстанню до поверхні інших клітин та увімкнути стандартний захист. Якщо арена порожня, перший допустимий кандидат приймається.
Стартовий гравець розміщується першим, потім боти за ID. Смерть видаляє клітину; маса не розсипається. Бот повертається з масою 20 через 3 секунди.

## Боти

Скінченний автомат: FLEE → HUNT → FORAGE → WANDER. Один стандартний рівень складності.
Огляд — радіус 25, оновлення 10 разів/секунду, без прихованої інформації поза радіусом.
- FLEE: незахищений більший противник, здатний поглинути бота, у межах огляду. Вибрати найближчу загрозу; напрямок від неї.
- HUNT: за відсутності загрози переслідувати найближчу незахищену клітину, яку бот може поглинути. Захищений бот не полює.
- FORAGE: найближча їжа в огляді.
- WANDER: seeded випадкова ціль усередині арени; змінити після досягнення відстані < 1 або через 2 секунди.

За рівності відстаней — найменший ID. Біля стіни прибрати компонент напрямку назовні; якщо отримано нуль, обрати seeded напрямок усередину. Боти мають ті самі швидкість, захист і поглинання, що й гравець.

## Матч і результат

Перед активною грою — відлік 3 секунди; симуляція матчу ще не йде.
Одиночний матч закінчується смертю гравця або після 18000 tick. Спочатку виконуються всі події останнього tick, потім результат. При смерті саме на останньому tick показати «Вас поглинули».
Місце: поточна маса спадно, кількість поглинутих клітин спадно, ID зростанням. Перше місце на таймері — перемога, інші місця — завершений матч з результатом.
На екрані: причина завершення, тривалість, поточна/остання маса, максимальна маса, їжа, поглинуті клітини, місце.
Після смерті місце обчислити за останньою масою перед смертю та масами інших на кінці tick; позначити «місце на момент смерті».
Пауза зупиняє tick, таймер, захист і респавн. Перезапуск створює новий матч, seed і статистику; тестовий запуск дозволяє заданий seed.

## Індикатор доступної здобичі та загрози
Клієнт показує зелений ореол для потенційної здобичі та червоний для небезпечнішого суперника. Перевірка canPreyOn спільна з canEat: перевага маси не менше 15%, обидві клітини без захисту. Фактичне поглинання додатково перевіряє геометричне перекриття. Ореол не означає, що контакт уже відбувся. Відстань вимірюється між поверхнями: повна інтенсивність до 10 м, smoothstep-згасання до нуля на 18 м. Для самого гравця, нейтральних клітин, меню та спостереження без живої клітини ореолу немає. Правила маси та зіткнень не змінені.
