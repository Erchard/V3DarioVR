# Смартфони
## Призначення
Грати за тією самою HTTPS-адресою без клавіатури й установлення застосунку. Спільна симуляція та авторитетний сервер залишаються без змін. Смартфон може приєднатися до кімнати ноутбука або VR.
## Керування
- Лівий джойстик: вперед/назад уздовж погляду, ліворуч/праворуч. Радіальна мертва зона 12%, амплітуда обмежена одиницею.
- Права сенсорна область: yaw/pitch з тією самою чутливістю й обмеженням pitch 85°, що й екранне керування мишею.
- ↑/↓: рух по світовій вертикалі; одночасне натискання взаємно компенсується.
- Ⅱ: пауза локально, меню без зупинки світу онлайн.
Pointer Events та capture дають незалежні пальці для руху, огляду й висоти. pointerup, pointercancel і втрата capture скидають відповідний жест. Пауза, blur, приховування вкладки та зміна орієнтації скидають весь ввід.
Основний pointer: coarse обирає сенсорний режим без User-Agent. При зміні основного вказівника активна гра переходить у меню, звідки запускається відповідний режим. VR має власні контролери; екранні сенсорні елементи у VR приховані.
## Інтерфейс
Горизонтальна орієнтація рекомендована, портретна не блокується. Панелі прокручуються, враховані safe-area відступи, інтерактивні ігрові кнопки щонайменше 48 CSS px. У низькому екрані прихована таблиця лідерів для видимості арени.
Pointer Lock, повноекранний режим і блокування орієнтації не потрібні. touch-action: none застосовується лише до ігрових контролів; меню зберігає звичайне прокручування.
Економний графічний профіль обмежує pixel ratio одиницею. Збережені налаштування не перезаписуються.
## Перевірки
Автоматизація: Chromium з touch/isMobile; три одночасні дотики через CDP, рух/огляд, cancel, відсутність руху після скасування, пауза/відновлення, поворот екрана, портретні меню, збереження графіки, спільний матч desktop/touch.
Це перевірка програмної поведінки, а не сертифікація мобільного GPU чи Safari.
Ручне приймання: фізичні Android Chrome та iPhone Safari; одиночний і онлайн матч, системні жести, екранна клавіатура коду кімнати, відновлення вкладки, виріз екрана, 20 хвилин нагрівання. Записати модель, версію браузера, FPS і практичну зручність. До виконання ці пункти залишаються NOT RUN.
