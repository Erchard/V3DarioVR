# V3Dario

[Грати онлайн](https://v3dario.onrender.com)

Тривимірна гра про поглинання та зростання. Грайте у Chrome на ноутбуці, у WebXR на Quest або разом в онлайн-кімнаті.

## Швидкий запуск

Потрібен Node.js 22.12+ (перевірено 22.19.0).

```sh
npm ci
npm run dev
```

Відкрийте **http://localhost:5173** у Chrome. Одна команда запускає Vite-клієнт та ігровий сервер на порту 8080. Ctrl+C завершує локальний запуск.

- **Грати проти ботів** — локальний матч без мережевих супротивників.
- **Онлайн** → створити кімнату → передати її восьмисимвольний код іншому гравцю → обом натиснути «Я готовий».
- **Увійти у VR** — на пристрої з WebXR. У звичайному браузері без шолома кнопка пояснює вимоги.

## Керування

| Дія | Chrome | Quest |
| --- | --- | --- |
| Огляд | Миша | Голова |
| Рух | W/S у напрямку погляду, A/D убік | Лівий стік у напрямку контролера |
| Угору / вниз | Space / Left Ctrl | Правий стік вертикально |
| Поворот | Миша | Правий стік горизонтально, 30° |
| Меню | Esc | B або просторове меню |
| Вибір | Миша | Промінь + trigger |

Якщо браузер відхилив Pointer Lock, оглядайтеся правою кнопкою миші.
У локальному режимі меню ставить світ на паузу. **В онлайні світ продовжується, і клітину можуть поглинути.**

## Quest 2

Для опублікованої гри потрібні HTTPS/WSS. За звичайною HTTP-адресою комп'ютера у локальній мережі immersive WebXR може бути недоступним.
Для локального налагодження з налаштованим ADB і Developer Mode:

```sh
adb reverse tcp:5173 tcp:5173
```

Після запуску dev-сервера відкрийте http://localhost:5173 у браузері Quest. Проксі Vite передає /socket на сервер комп'ютера. Фізична перевірка Quest 2 потрібна перед VR-релізом.

## Онлайн з інших пристроїв

Скопіюйте .env.example у .env. Додайте точну адресу, з якої відкриватиметься клієнт, до ALLOWED_ORIGINS. Наприклад, для іншого ноутбука у LAN: http://192.168.1.10:5173. Не заміняйте allowlist на безумовний дозвіл усіх Origin.

Сервер читає .env під час старту. Vite використовує VITE_SERVER_URL, якщо потрібно вказати окремий сервер; за замовчуванням /socket на тому самому origin.
Для доступу з інтернету потрібне окреме розгортання. Приклад HTTPS reverse proxy — deploy/Caddyfile. Гра опублікована на https://v3dario.onrender.com.

## Перевірки

```sh
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:load
```

Навантажувальний smoke за замовчуванням: 3 кімнати × 8 клієнтів, 30 секунд. Для іншого профілю задайте LOAD_ROOMS (1–10) та LOAD_SECONDS (1–3600) через змінні середовища.
У PowerShell: $env:LOAD_ROOMS='10'; $env:LOAD_SECONDS='60'; npm run test:load.
Це локальна перевірка; вона не замінює годинний тест на цільовому сервері.

## Структура

- packages/core — спільна 3D-симуляція, їжа, поглинання, боти, спавн.
- packages/protocol — типи та сувора валідація вводу.
- apps/client — Three.js, desktop/WebXR керування, HUD, меню, онлайн.
- apps/server — авторитетні кімнати, snapshots, reconnect, ліміти.
- tests — правила, керування, сервер, браузер і навантаження.
- docs — специфікації й звіт реалізації.
- deploy — приклад зовнішнього HTTPS reverse proxy.

П'ятихвилинні матчі; одиночна смерть завершує спробу, онлайн дозволяє відродитися через 3 секунди. Поділ, віруси та викидання маси не входять у початковий обсяг v0.1.

## Опублікувати онлайн

[Розгорнути на Render Free](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2FErchard%2FV3DarioVR)

Увійдіть у Render, підключіть репозиторій, перевірте план Free та запустіть Blueprint. Параметри сервера вже у render.yaml. Після успішної збірки отримана HTTPS-адреса обслуговує клієнт, VR і мультиплеєр.

Безкоштовний сервер засинає після 15 хвилин бездіяльності; наступний запуск займає близько хвилини. Деталі й ліміти — у [інструкції](docs/11-free-publishing.md).

## Смартфони
Відкрийте ту саму адресу на телефоні. Сенсорне керування вмикається для основного грубого вказівника (pointer: coarse): лівий джойстик — рух, права область — огляд свайпом, ↑/↓ — вертикальний рух, Ⅱ — меню. Горизонтальна орієнтація зручніша; портретна також працює. Поворот екрана ставить локальну гру на паузу та скидає натиснення; онлайн-світ продовжується.
Економна графіка ввімкнена за замовчуванням для нових налаштувань сенсорного пристрою. Збережений вибір користувача має пріоритет.
Автоматичні перевірки touch у Chromium не замінюють вимірювання FPS, нагрівання та зручності на реальному Android/iPhone. [Мобільне приймання](docs/12-mobile.md).
